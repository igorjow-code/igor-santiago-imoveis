# Instagram assets — hospedagem para postagem automática

Estas imagens **não fazem parte do site** (`build_site.py` não lê esta pasta). Elas existem
aqui só para ter uma **URL pública HTTPS** que a Meta Graph API consegue buscar ao publicar
no Instagram (`raw.githubusercontent.com/igorjow-code/igor-santiago-imoveis/main/...`).

Fonte e controle de versão real: `igris-os/clientes/is-imoveis/instagram/render/` (repositório
privado). Para atualizar uma arte, editar lá, re-renderizar e copiar o PNG final para cá.

Fila de publicação (quais posts, em que ordem, com que legenda): `igris-os/clientes/is-imoveis/instagram/queue.json`.
